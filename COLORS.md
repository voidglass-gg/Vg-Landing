# Palette VoidGlass

| Usage | Couleur | Hex |
| --- | --- | --- |
| Fond principal | Presque noir | `#07080D` |
| Fond secondaire / cartes | Bleu pétrole | `#0E3442` |
| Accent principal | Bleu électrique | `#05EBEB` |
| Accent secondaire | Violet profond | `#280387` |
| Texte principal | Blanc froid | `#F4F7FA` |
| Texte secondaire | Bleu gris | `#789FBF` |

Les couleurs sont centralisées dans les variables `:root` du fichier `assets/css/styles.css`.

Le cyan sert aux actions et aux repères importants. Le violet reste un accent de profondeur et n’est pas utilisé comme couleur de texte.
